# KO ABS

A [KOReader](https://koreader.rocks/) plugin for browsing [Audiobookshelf](https://www.audiobookshelf.org/) libraries on your e-reader.

## Features

- Connect to an Audiobookshelf server.
- Authenticate with your account.
- Browse libraries and their books.

## Installation

Copy `ko-abs.koplugin/` into your KOReader `plugins/` directory and restart KOReader.
